This program writes one judged incident line to `entry.txt`, checking that it is under 200 characters, contains a comma and the word `README`, and names both a tool and a duration before reading the bytes back to prove they match. The line lands because the work is circular — nine minutes spent rewriting a README to say nothing changed — and the punchline is the commit history, where that no-op is the only change.

## How it runs

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```
